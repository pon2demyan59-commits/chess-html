# Шахматы в свободное время

Браузерные шахматы против компьютера на HTML, CSS и JavaScript. В меню можно выбрать сторону и уровень бота от 1 до 10. Результаты завершённых партий сохраняются на устройстве по стороне и сложности. Есть три задачи «мат в один ход».

Ходы проверяет включённая в проект библиотека chess.js 1.4.0: шах, мат, пат, обе рокировки, взятие на проходе и превращение пешки в ферзя, ладью, слона или коня. Учтены ничьи из-за невозможности мата, заявление по троекратному повторению или правилу 50 ходов и автоматическая ничья по пятикратному повторению или 75 ходам. Компьютер заявляет доступную ничью сам.

Можно открыть `index.html` напрямую или запустить через локальный HTTP-сервер. Интернет для партии не нужен.

Во время партии показывается запись ходов. После окончания доступен разбор: переход по ходам, начальная и конечная позиции, копирование PGN для загрузки в шахматный анализатор. Оценка ходов движком Stockfish пока не включена.
