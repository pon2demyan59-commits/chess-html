# Шахматы в свободное время

Браузерные шахматы на HTML, CSS и JavaScript: компьютер с шестью уровнями сложности (Пешка, Слон, Конь, Ладья, Офицер, Король), два игрока на одном экране и онлайн PvP. Ходы выполняются перетаскиванием мышью или пальцем. Анализ партии в интерфейсе отключён.

Есть задачи на мат в 1–5 ходов и тактические комбинации. Первая сессия в этой вкладке бесплатна целиком и сохраняет это правило после обновления. Первые пять вводных задач бесплатны всегда; они содержат подсказку о стартовой фигуре. В последующих сессиях энергия начинает расходоваться после трёх минут накопленного активного времени. Рекламные предложения появляются только вне бесплатного знакомства и после пяти завершённых задач или партий. Бот по умолчанию — Пешка. Просьб оценить игру нет.

Остальные новые задачи расходуют энергию, повтор решённых бесплатный. Максимальный и начальный запас энергии — 50. Энергия восстанавливается со временем, за завершение партии и по желанию за rewarded-рекламу (+10, до максимума 50).

Правила проверяет локальная chess.js 1.4.0. Поддерживаются рокировка, взятие на проходе, превращение пешки и ничьи. При обновлении в той же вкладке восстанавливаются позиция и история ходов; старые сохранения только с FEN загружаются без утраченной ранее истории.

SDK Яндекс Игр подключается через `/sdk.js`. Игра доступна без авторизации; Яндекс ID используется для облачных достижений, статистики, энергии и настроек. Текущая партия хранится в sessionStorage, а не в облаке. При объединении достижений сохраняется объединение решённых задач, счётчики выбирают максимум; независимые результаты разных устройств не суммируются. Энергия и настройки выбираются по времени изменения.

Онлайн PvP использует Supabase и требует сети и настроенного серверного API. Облачные сохранения и реклама требуют платформы Яндекс Игр. Клиент Supabase 2.117.2 включён в архив вместе с лицензией; загрузка с CDN не нужна.

Для локальной разработки запускайте HTTP-сервер из корня проекта, например `python -m http.server 8000`; отсутствие SDK локально допустимо.

## Языки

Русский, английский, испанский и немецкий. Игра сначала учитывает сохранённый выбор, затем язык Яндекс SDK; вне платформы — язык браузера. Для неподдерживаемого языка используется английский. Переключатель доступен на стартовом экране и в меню. Изменение языка перезагружает интерфейс; партия и история остаются в sessionStorage. Ники и шахматная SAN-нотация не переводятся. Каталог находится в `js/translations.js`.

## Релиз

Выполните `python scripts/build_release.py`. Архив создаётся в `dist/chess-yandex-release.zip`: только index.html, assets, css, js, vendor и лицензия chess.js. Скрипт проверяет пути, размер, ссылки и целостность ZIP. Документация, инструменты и Git в релиз не входят.

Перед модерацией пройдите [контрольный список](docs/release-checklist.md). Наличие SDK в коде и успешная упаковка не заменяют проверку загруженной сборки.

## Оформление и размер доски

Вариант «Классика» использует 12 стандартных SVG-фигур Cburnett с Wikimedia Commons. Авторство, источники и BSD-лицензия включены в `assets/pieces/classic/LICENSE`. Фигуры включены в архив и не требуют внешних запросов.

Доска использует оставшееся место экрана без ограничения ширины игрового блока 1130 px. На широком экране и в альбомной ориентации невысокого экрана игроки, ходы, статус и действия находятся справа; в портретном мобильном режиме используется компактная лента ходов. Размер квадратной доски рассчитывается по фактическим размерам области.
