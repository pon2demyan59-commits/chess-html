# Шахматы в свободное время

Браузерные шахматы против компьютера на HTML, CSS и JavaScript. После стартовой афиши открывается основное меню с выбором стороны и уровня бота от 1 до 10. Результаты завершённых партий сохраняются на устройстве отдельно по стороне и уровню сложности. В меню есть три задачи «мат в один ход».

В игре есть шах, мат, пат и рокировка. Взятие на проходе пока не реализовано.
